주방 동선 계획 설명

▶
숯 동선: 북측 납품문 → 숯 보관창고 → 숯 점화 스테이션 → 픽업 카운터(PASS Window) → 서빙직원 → 각 테이블
▶
식재료 동선: 북측 납품문 → 냉장/냉동 보관 → 조리·준비대 → 반찬·소스 작업대 → 픽업 카운터(PASS Window) → 서빙 → 테이블
▶
서빙 동선: 픽업 카운터 → 서버 스테이션 → 각 테이블 (단방향 통로 유지)
▶
반납/세척 동선: 홀 반납 → 픽업 카운터 내측 → 세척 구역 → 식기 보관대 → 재사용
📌 숯불 주방 추가 검토 필요 사항
1. 테이블별 개별 후드 덕트 (숯불 그릴 연기·CO 배기) — 구조체 관통 여부 사전 협의 필요
2. 숯 점화실: 방화구획 + 시간당 20회 이상 강제 환기, CO·CO₂ 감지기 설치 의무
3. 숯 납품 동선이 홀 고객 동선과 교차하지 않도록 북측 외부 납품문 확보 필수
4. 보건소 영업신고 기준: 주방 면적 홀의 1/3 이상 권장 (현 약 28% → 추가 협의 가능)
